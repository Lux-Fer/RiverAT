# RiverAT V0.2.2：知识控制台与过期清理

> V0.2.1 让知识有作用域、有效期和反馈；V0.2.2 让这些能力有一个可操作的面。

## 1. 知识控制台

新增 `/knowledge` 页面（工程师/管理员可访问）：

- 汇总：总数、待确认、已确认、已归档、过期；
- 筛选：关键词、类型、作用域、状态、产品；
- 列表：kind、标题、状态、scope、置信度；
- 展开：正文、产品、有效期、反馈统计、来源事件/任务链接；
- admin：确认、归档、归档全部过期知识。

可见性：

- `global`：所有人可见；
- `product`：团队可见；
- `user`：只有 owner 可见；admin 也不通过控制台查看其他用户的私有知识。

## 2. 过期清理

检索一直会过滤过期知识；控制台额外提供：

- “归档过期知识”按钮（admin）；
- 把 `valid_until <= now()` 且仍为 tentative/approved 的知识标记为 `archived`；
- 每条写 `knowledge.expire` 审计和 `knowledge.expired` 事件。

这是显式清理，不是后台定时任务；后续可交给 worker 定时执行。

## 3. 人工审核

admin 在控制台把知识改为：

- `approved`：人工确认可用；
- `archived`：不再参与检索。

审核写 `knowledge.review` 审计和事件。反馈（V0.2.1）仍由任务详情触发；两者是不同信号：
反馈是“这次任务里有没有用”，审核是“这条知识是否长期可信”。

## 4. 验收

- 控制台能看到 global / product / 自己的 user 知识；
- 看不到其他用户的 user 知识；
- 筛选和关键词可用；
- 展开能看到正文与来源事件；
- admin 可确认/归档；
- 过期知识被归档，且有审计和事件；
- 全量测试通过。

**2026-11-12 验收：223 passed / 4 skipped。**

## 5. 本版不做

- 知识正文编辑；
- 团队作用域；
- 后台定时 TTL 清理；
- 知识导入/导出；
- 向量检索与 M4 评测。
