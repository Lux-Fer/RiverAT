# 字体

- **IBM Plex Sans SC**（SIL Open Font License 1.1），全站 UI 字体。
- 文件：
  - `IBMPlexSansSC-Regular.woff2`（weight 400，1.13 MB）
  - `IBMPlexSansSC-SemiBold.woff2`（weight 600，1.19 MB）
- 从官方 woff2 子集化：GB2312 汉字 + 拉丁 + 常用标点/箭头/几何符号；未覆盖字符回退系统 `PingFang SC` / `Microsoft YaHei`。
- 代码、参数、JSON 仍使用等宽（Cascadia Mono / Consolas）。

来源：https://github.com/IBM/plex/tree/master/packages/plex-sans-sc
许可：SIL OFL 1.1
